### IMDb Movie Rating Analysis Project

This project analyzes IMDb movie data using Python, Pandas, Power BI.  

#### Features:
- Data cleaning and preparation
- Analysis of movie ratings and genres
- Visualizations: bar charts, histograms, scatter plots
- Built a Power BI dashboard to visualize key insights interactively
  
- Insights:
  - Most movies have ratings between 6 and 8
  - Drama and Action are the most common genres
  - Movies with more votes tend to have stable and reliable ratings
  - Very low-rated movies are fewer in number
  - The distribution of ratings shows that most movies are well-received

#### Tools:
Python, Pandas, Matplotlib, Power BI
